# Hello Dart

**Book / Chapter:** Fundamentals – Ch.1
**Tags:** #basics #entry-point

## TL;DR
Every Dart program starts from a top-level `main()` function; `print()` writes to the console.

## الشرح
أي برنامج Dart بيبدأ تنفيذه من دالة `main()`. لازم تكون موجودة وإلا البرنامج مش هيشغل. دالة `print()` بتطبع أي قيمة تديها في الـ console.

## Code Example
See `main.dart` in this folder.

## Common Mistake
Forgetting the `void main()` entry point, or misspelling it (e.g. `Main()`), which stops the file from running as a program.
